# Superstore Sales Analysis — End-to-End Data Analytics Project:

A complete data analytics project where I cleaned, transformed, analyzed, and visualized Superstore sales data to uncover actionable insights across sales performance, profitability trends, customer segments, and regional performance.
This project demonstrates strong capabilities in Excel, Pivot Tables, Dashboards, KPIs, Data Cleaning, Data Modeling, and Insight Generation

# Project Overview
The goal of this project was to perform a full analytical workflow:
1. Data Understanding & Cleaning
2. Data Preparation & Transformation
3. Exploratory Data Analysis (EDA)
4. Pivot-table based deep-dive analysis
5. Interactive Excel Dashboard creation
6. Business insights & recommendations

# Dataset: 
The dataset contains detailed transactional information from a fictional retail store, including:
Order details (Order ID, Date, Ship Mode);
Customer info (Segment, Region, State);
Product hierarchy (Category, Sub-Category);
Financial metrics (Sales, Quantity, Discount, Profit)
Total records: ~10K rows

3. Analytical Thinking:	Trend analysis, profitability evaluation, segment performance

# Data Cleaning & Preparation
Key cleaning tasks performed:
1. Standardized date formats
2. Handled missing values
3. Corrected inconsistent category & segment names
4. Removed duplicate entries
5. Added calculated fields: Profit Margin, Discount Impact, YoY Sales Growth, Contribution to Total Sales

# Exploratory Data Analysis (Pivot Table Findings)
1. Sales & Profit by Category:
Technology category generated highest sales
Office Supplies had high sales but comparatively lower profit margin
Furniture had negative profit in multiple regions due to high discounts

2. Regional Performance:
West region performed the strongest in both sales & profitability
Central region showed profitability challenges

3. Customer Segment Analysis:
Corporate & Consumer segments drove ~70% of revenue
Home Office segment had good average order value but inconsistent profitability

4. Discount Impact Analysis:
Heavy discounting in Furniture → consistently negative profit
Moderate discount performed well in Technology products

# Business Recommendations
1. Reduce discounting in loss-making furniture categories.
2. Invest more in high-performing regions like West to maximize gains.
3. Improve marketing in Central and South regions with targeted offers.
4. Focus on high-profit sub-categories such as Accessories & Phones.
5. Analyze underperforming products for possible discontinuation.
